# پرامپت ممیزی مستقل دور دوم برای GLM-5.3-Flash (Z.ai)

سلام GLM، ممیز مستقل فنی پروژه حامی‌کارت (HamiCard v1.0).
گزارش ممیزی دور دوم (Review Pass 2) برای هسته و لایه سرویس‌های حامی‌کارت تقدیم می‌شود:

کدها و اصلاحات فاز ۱، فاز ۲ و کلیه سرویس‌ها و لایه REST API فاز ۳ با موفقیت پیاده‌سازی شده و تمامی ۱۴ سوئیت آزمون خودکار مستر (۷۴ تست جامع) با موفقیت ۱۰۰٪ پاس شده‌اند (صفر خطا):

۱. **ناوردای سهمیه ویزیت استانی (AC-07):**
   - کوئری اتمیک شرطی در سطح PostgreSQL پیاده‌سازی شد:
     `UPDATE memberships SET used_visits = used_visits + 1, remaining_visits = remaining_visits - 1, status = CASE WHEN remaining_visits - 1 = 0 THEN 'EXHAUSTED' ELSE status END WHERE id = $1 AND status = 'ACTIVE' AND remaining_visits >= 1`
   - تضمین قطعی صفر شدن منفی (Zero Negative Visits) و رد اضافه درخواست‌ها در سطح دیتابیس تحت ۵۰ درخواست هم‌زمان.

۲. **ناوردای تسویه‌ها (AC-12):**
   - ایندکس جزئی یکتای شرطی: `WHERE status IN ('PENDING', 'PROCESSING', 'APPROVED') AND deleted_at IS NULL`
   - تبدیل خطای ۲۳۵۰۵ به خطای ساختاریافته ۴۰۹ Conflict دامنه.
   - لیس ورکر مالی (`lease_expires_at`) و مکانیزم Watchdog خودکار جهت بازیابی تسویه‌های یتیم.

۳. **چرخه نشست و چرخش توکن (AC-14 و AC-15):**
   - جدول `refresh_tokens` در PostgreSQL به عنوان مرجع واحد (SSOT).
   - ساختار تبار توکن با `family_id`؛ ابطال فوری کل خانواده توکن در صورت Replay Attack.
   - مهلت ۵ ثانیه‌ای (Grace Period) برای درخواست‌های موازی شبکه.

۴. **مدل‌سازی ۶ نقش PRD و RBAC:**
   - ۶ نقش تفکیک‌شده: `SUPER_ADMIN`, `ADMIN`, `SUPPORT`, `DOCTOR`, `AGENT`, `USER` با ۲۶ مجوز مستقل.
   - گیت‌های تایید پزشک و نماینده به صورت Fail-Closed.

۵. **اعتبارسنجی‌ها، پروفایل و امنیت PII فاز ۳:**
   - الگوریتم دقیق کد ملی (mod 11) با حذف ارقام نامعتبر تکراری.
   - الگوریتم Luhn mod 10 کارت شتاب.
   - الگوریتم ISO 7064 Mod 97-10 شماره شبای IR.
   - مدل‌سازی ۳۱ استان و شهرهای کشور و ماسک PII بر اساس نقش.

۶. **دامنه‌های کسب‌وکاری و لایه کامل REST API فست‌پی‌آی:**
   - سرویس‌های ثبت ویزیت، لغو ویزیت، کیف پول، ماشین وضعیت دوگانه لجستیک و مالی پرونده‌های فروش (AC-09, AC-10)، درگاه پرداخت و فعال‌سازی کارت (AC-06)، نظرات و اعلان‌ها.
   - ۱۱ روتر تحت `/api/v1` در FastAPI با ممیزی امنیتی Startup Fail-Closed برای تنظیمات ۱۸ گانه `OPEN-01..18`.
   - پورتال وب و نوار شناور هوشمند نصب PWA برای موبایل (اندروید و iOS Safari).
